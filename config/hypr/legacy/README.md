# Legacy Hyprlang Configuration Backup

This directory contains the original Hyprlang (`.conf`) configuration files preserved during the migration to the native Hyprland Lua API.

## Archived Files

- `hyprland.conf`: Original root compositor configuration
- `exec.conf`: Original autostart service definitions
- `keybinds.conf`: Original keybindings and submaps
- `windowrules.conf`: Original window rules

## Date Archived
November 2026 (Targeting Hyprland native Lua architecture).

## Note
These files are preserved for historical reference and backup purposes. The active compositor configuration is now powered entirely by native Lua files located in `../` (`hyprland.lua`, `programs.lua`, `exec.lua`, `keybinds.lua`, `windowrules.lua`).
